# Security

BuffBot is a plugin for a game client. It reads chat, drives the plugin API of the client it runs
in, and serves an operator console on the loopback interface.

**Report anything security-relevant privately to security@solrlabs.com** rather than opening a
public issue. That includes anything that would let a third party drive somebody's bot, read their
console, or reach the machine it runs on.

Please include what you did, what happened, and the version (`plugin.json`'s `version`) you saw it
on. Expect an acknowledgement within a week.

There is no bounty program.
